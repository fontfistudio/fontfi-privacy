FontFi Privacy Policy

Last updated: October 20, 2026

Overview

FontFi is a Chrome extension that helps users identify fonts, inspect typography properties, and analyze font usage on webpages.

Data Collection and Use

FontFi processes webpage elements and typography properties to provide its core functionality.

Webpage analysis is performed locally in the user's browser. FontFi does not transmit analyzed webpage content to the developer or third parties.

FontFi does not sell user data or use it for advertising, profiling, or creditworthiness assessment.

Data Storage

FontFi does not store analyzed webpage content on external servers.

Third-Party Services

FontFi does not use third-party analytics or advertising services.

Changes to This Policy

This policy may be updated if the extension's functionality or data practices change.

Contact

For privacy-related questions, please use the contact information provided on the FontFi Chrome Web Store listing.
