Transparency & privacy

Privacy Policy

Last updated: October 30, 2026

FontFi is a Chrome extension that identifies fonts, inspects typography, analyzes page font usage, compares saved references and exports review findings.

Data Collection and Use

After you activate FontFi, it processes page elements, computed CSS, generated text, short ordinary-page text samples, page titles and URLs, reachable shadow DOM and same-origin frames. Canvas text measurements estimate font availability. Analysis supports inspection, highlighting, comparison and rechecking and is performed locally. FontFi does not transmit analyzed page content to the developer or third parties.

Signed-in and private-page text, URLs (including query strings and fragments), element identifiers and your notes can contain personal or confidential information. Typography sampling excludes input/textarea values, selected option text and detected editable-field contents; password controls are excluded from scans. Inspection of controls or detected editable fields uses a placeholder. These protections do not recognize all sensitive information rendered as ordinary page text.

FontFi does not sell user data or use it for advertising, profiling, creditworthiness assessment or unrelated purposes.

Data Storage

FontFi does not store analyzed webpage content on external servers. Projects use chrome.storage.local, scoped to a site origin or individual local file. Stored information includes references, font properties, short page-text samples, labels, page/frame URLs, element routes and IDs, capture/check times, viewport dimensions, comparisons, statuses and user-written notes. Records also contain local identifiers, revisions and save times. First-use hint preferences are saved when inspection modes are used, even without a saved finding.

FontFi does not use Chrome synchronized storage for projects. View options (Hide icons and Font details) are stored locally with each site's project and restored when that project opens. Preview text, search, sort and export options remain in the current panel rather than stored project preferences. The preview feature does not add custom preview text to saved findings or reports. Rendering uses fonts available to the page and may cause the browser to load page-defined webfonts through normal page font-loading mechanisms.

Retention and Deletion

Projects have no automatic expiry and survive panel closure, reloads and clearing browsing history. Scan data and temporary state are held in memory; page-associated caches can remain until the page reloads or closes.

Delete references in Manage and findings in Review; edit or clear notes in findings. Reset only deselects the active reference. Reference deletion does not delete snapshots already retained inside findings; delete those findings separately. Finding deletion does not delete independent references. Hint preferences and project metadata can remain after visible items are deleted. This release has no dedicated clear-all control. Removing the extension clears its local extension storage.

When a legacy project without the current sample-safety marker is loaded, older automatic samples and derived labels are removed; user-written notes remain. This happens per opened project, not as an immediate purge of all stored sites.

Clipboard and Exports

Copy actions write the selected CSS font stack, typography CSS or color to the system clipboard. FontFi does not read clipboard contents. Clipboard history, synchronization and other applications may retain copies.

HTML, JSON and Markdown exports create files on your device, without uploading them. You select scan overview, font/CSS inventory, heuristic suggestions, saved findings and references. Saved findings and references are exportable without a new scan; unavailable or outdated scan data is identified.

Redact page data starts enabled each time a panel opens. It removes or replaces page URLs/title, routes, element IDs, text samples and custom labels. Include manual notes is a separate choice, off by default: enabling it includes notes even with page-data redaction enabled. Disabling redaction includes page context. These choices affect preview/downloads, not local projects or clipboard actions.

Redaction does not guarantee anonymity: selected sections can retain typography, counts, timestamps, dimensions, statuses and internal finding/reference identifiers. CSS and included notes may contain identifying information. Review the preview and exclusions before sharing. HTML preview uses a local sandboxed frame with a text fallback and does not upload the report. Downloaded files and clipboard copies must be managed separately and are not deleted when project items or the extension are removed.

Permissions

  • activeTab: temporary page access after you activate FontFi.
  • scripting: inject the bundled inspection code and interface.
  • storage: save projects and first-use hint preferences locally.

FontFi does not request browsing-history, cookies, clipboard-read or persistent all-sites host permissions. File inspection requires Chrome's file-URL access setting. Web-accessible packaged logos are not an all-sites inspection permission.

Third-Party Services

FontFi does not use third-party analytics, telemetry, tracking, advertising or a remote project/account service. The reviewed extension contains no application network requests uploading analysis or notes. Visiting the policy on GitHub Pages is separate and subject to GitHub's privacy practices.

Optional Support through Boosty

Choosing Support FontFi opens https://boosty.to/fontfi.studio/donate in a new tab. Supporting FontFi is voluntary and is not required to use the extension's features.

Boosty is an external service. Donations and any account/payment interactions take place there under Boosty's own terms and privacy practices. The FontFi extension does not collect or process payment details, integrate a payment system, verify donations or send scanned page content, projects or notes to Boosty. The link uses no-referrer protection. When you visit Boosty, its website processes information associated with your visit under its own policies, separately from FontFi's local analysis.

Your Choices

You choose pages to inspect, saved references/findings, notes, clipboard actions and exports. Use the deletion controls above or remove the extension to clear local extension storage. For privacy questions or requests concerning applicable rights, use the contact below. The developer cannot retrieve local projects through the extension.

Changes to This Policy

This policy may be updated if the extension's functionality or data practices change.
